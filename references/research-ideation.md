# Research Ideation (Pre-Gate 0)

Purpose: structured brainstorming before literature search. Use when starting a new paper from scratch.

## 5W1H Framework

- **What** problem are you solving? Define the gap in one sentence.
- **Why** does it matter? Quantify impact or consequence of the gap.
- **Who** are the stakeholders? (researchers, practitioners, end users)
- **When/Where** is this applicable? (domain, scale, deployment context)
- **How** might you approach it? List 2-3 preliminary methods without committing.

## Gap Analysis (5 types)

| Gap Type | Question to Ask |
|----------|----------------|
| Literature | What hasn't been studied or is under-explored? |
| Methodological | What existing methods fail or are limited? |
| Theory-to-practice | What theory lacks empirical validation? |
| Interdisciplinary | What cross-domain transfer is unexplored? |
| Temporal | What emerging trend creates new opportunities? |

- For each gap type, list at least one concrete instance relevant to your topic.

## Research Question Formulation

### SMART Criteria
- **S**pecific: narrowly scoped, not vague
- **M**easurable: clear success metric
- **A**chievable: feasible within resource constraints
- **R**elevant: addresses an identified gap
- **T**ime-bound: realistic timeline

### FINER Scoring (rate 1-5 each)

| Criterion | Score | Notes |
|-----------|-------|-------|
| Feasible | /5 | Resources, data, compute available? |
| Interesting | /5 | Would peers care? |
| Novel | /5 | Not a rehash of prior work? |
| Ethical | /5 | No harm, bias, or privacy concerns? |
| Relevant | /5 | Addresses real need? |

- Threshold: total ≥ 18/25 to proceed.

## Method Selection Matrix

| Research Goal | Candidate Methods |
|---------------|-------------------|
| Improve SOTA accuracy | Novel architecture, loss function, training strategy |
| Improve efficiency | Pruning, distillation, quantization, architecture search |
| Understand phenomenon | Probing, ablation, mechanistic interpretability |
| New task/benchmark | Dataset construction, evaluation protocol design |
| Bridge domains | Transfer learning, domain adaptation, multi-task |
| Scale existing method | Distributed training, memory optimization, approximation |

## Output Deliverables

- [ ] Structured ideation document (5W1H + gap analysis)
- [ ] 3-5 candidate research questions with FINER scores
- [ ] Preliminary keyword list (10-20 terms for literature search)
- [ ] Initial method shortlist (2-3 approaches)

## Integration

- Feeds into Gate 0 research snapshot (see `references/research-workflow.md`)
